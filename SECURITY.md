# Политика безопасности

## Границы доверия

Любая форма, имя файла, документ, ответ AI и callback внешнего сервиса считаются
недоверенными. AI не принимает решений о создании сделки и не выполняет команды.

## Основные меры

1. Поддерживается только актуальный PHP 8.4 patch-релиз, не ниже 8.4.27.
2. Загруженные файлы находятся вне `document_root` и не исполняются веб-сервером.
3. Допустимы только PDF и XLSX размером до 12 MiB.
4. Проверяются расширение, MIME, magic bytes и структура XLSX.
5. Исходное имя никогда не используется как имя файла на диске.
6. Скачивание выполняется только через административный endpoint с проверкой прав.
7. Все изменяющие операции требуют Bitrix session token.
8. В журнал не записываются содержимое документов, секреты и полные персональные данные.
9. Создание сущности в Битрикс24 возможно только после явного подтверждения менеджера.
10. Секреты Gateway запрещено хранить в Git или настройках, доступных из браузера.
11. Webhook Битрикс24 хранится только в secret storage/окружении.
12. REST-клиент разрешает только три метода, HTTPS и точный hostname портала.
13. Повторный экспорт ищет сделку по внешнему UUID и не должен создавать дубликат.

## Сообщение об уязвимости

Не публикуйте сведения об уязвимости до исправления. Передайте описание владельцу
установки с шагами воспроизведения, версией окружения и минимальным примером.
