# Безопасное развертывание

## PHP

Минимум — PHP 8.4.27. Перед каждым развертыванием устанавливайте последний
доступный security/patch-релиз поддерживаемой ветки.

Рекомендуемые параметры:

```ini
expose_php=Off
display_errors=Off
log_errors=On
allow_url_include=Off
session.upload_progress.enabled=0
upload_max_filesize=12M
post_max_size=14M
max_file_uploads=2
max_execution_time=30
memory_limit=256M
```

Используйте PHP-FPM от отдельного непривилегированного пользователя. Запретите
исполнение файлов в каталоге приватного хранилища на уровне ОС и веб-сервера.

## Приватное хранилище

По умолчанию модуль ожидает каталог рядом с document root:

```text
/var/www/site/                 # document root
/var/www/b2b-request-private/  # приватные документы
```

Владельцем должен быть пользователь PHP-FPM. Права каталога — `0700`, файлов —
`0600`. В production задайте абсолютный путь в настройках модуля.

## Обновления

- ежедневно проверяйте security advisory PHP, ОС и 1С-Битрикс;
- применяйте критические обновления по аварийному регламенту;
- храните резервные копии зашифрованными;
- периодически проверяйте восстановление, а не только создание резервной копии.

## Gateway и Worker

Gateway слушает только loopback/private network. Не публикуйте порт `8780` в
Интернет. `HMAC_SECRET` должен содержать не менее 32 случайных байт и передаваться
через secret storage, а не `.env` в репозитории.

Worker запускается в отдельном virtualenv или контейнере без shell, компиляторов,
учетных данных Битрикс24 и исходящего сетевого доступа. Общий Python runtime
запрещен: посторонние пакеты увеличивают поверхность атаки и затрудняют аудит.

Каталоги `queue` и `storage` доступны только системным пользователям Gateway и
Worker. На Windows используйте NTFS ACL; на Linux — отдельную группу и права не
шире `0770` для каталогов и `0660` для файлов. Веб-сервер не должен раздавать эти
каталоги.

## Переменные окружения

Используйте отдельный secret storage systemd, Docker/Kubernetes secrets или
хранилище панели сервера. Не передавайте секреты через параметры командной строки.

Обязательные переменные:

- `SAFEAI_GATEWAY_URL` — только `http://127.0.0.1:8780` для MVP;
- `SAFEAI_GATEWAY_HMAC_SECRET` — не менее 32 случайных байт;
- `SAFEAI_RATE_LIMIT_SECRET` — отдельный секрет не менее 32 байт для хеширования IP;
- `SAFEAI_QUEUE_ROOT` — абсолютный путь к приватной очереди;
- `SAFEAI_STORAGE_ROOT` — тот же каталог документов, который использует модуль;
- `SAFEAI_BITRIX24_WEBHOOK_URL` — секретный URL входящего вебхука;
- `SAFEAI_BITRIX24_ALLOWED_HOST` — точный hostname портала без схемы и пути.

Подробности REST-интеграции: [BITRIX24.md](BITRIX24.md).
